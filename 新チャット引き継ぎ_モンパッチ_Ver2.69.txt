■ 現在の確定方針
- 盤面の外周にある金属フレームは「細く再調整」ではなく、いったん撤去する
- 代わりに、盤面の裏に「透過30%の背景」を置く
- これは盤面を見やすくするための処置であり、装飾強化が目的ではない
- ブロック自体のサイズは原則変更しない
- 盤面の実配置エリア（9×7のブロック配置領域）も原則変更しない
- 意図は「フレームの干渉をなくすこと」であり、それ以外の見た目変更は最小限にする
- 以前ユーザーは「パズル背景はもういらない」と言っているため、盤面裏の背景はシンプルな半透明1枚でよい

■ 今回の実装内容（Ver2.69）
1. 金属フレーム画像による boardWrap::before を無効化/非表示にする

■ Termux 側の運用情報
ユーザーは .bashrc に以下の upload 関数を登録済み：

upload() {
  cd ~/storage/downloads/match-vs || return

  git add .

  if git diff --cached --quiet; then
    echo "変更はありません"
    return
  fi

  git commit -m "Auto update $(date '+%Y-%m-%d %H:%M')"
  git push
}

これで Termux 起動後に
- source ~/.bashrc
- upload
で更新できる状態。
