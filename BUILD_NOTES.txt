Meteor StrikeR Ver.2.76 ビルドノート

基準: GitHub main 230e8d1（Ver.2.75）

主な変更:
- 矢印発光を0.72秒周期から1.8秒周期へ緩和
- 矢印の最大輝度を1.50から1.28、最大光彩を20pxから12pxへ抑制
- 小惑星の赤いマグマ亀裂へ2.8秒周期の呼吸発光を追加
- ブラックホールの紫色外周へ3.4秒周期の脈動発光を追加
- 複数特殊ブロックの発光位相を盤面位置ごとに分散
- MutationObserverを盤面直下の再描画監視に限定し、発光クラス変更による再適用ループを解消
- 画面表示、ブラウザタイトル、ランキング送信値をVer.2.76へ更新
- PWAのAPP_VERSION、version.json、Service Workerキャッシュを2.76.0へ更新
- 通常版とPWA版のコードおよびバージョン情報を同期
- SHA256SUMS.txtを現行ファイルから再生成

設計上の注意:
- 発光実装は表示専用で、消去判定・スコア計算・落下処理には影響しない。
- 小惑星とブラックホールは元画像を複製合成し、素材の明部だけを穏やかに強調する。
- prefers-reduced-motion有効時は点滅せず、弱い固定発光とする。
- 発光実装は通常版とPWA版のjs/game-ui.jsで同一。
- 内部データ名 flower / bomb / chain / ice は互換性維持のため変更していない。
- 次回の定期クレンジングはVer.2.80。Ver.2.76完成時点であと4回。
